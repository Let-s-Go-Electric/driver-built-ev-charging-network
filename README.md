
  # Let's Go Electric!

  | The EV Charging Network built for and by drivers.

  The Let's Go Electric! app is a community platform where drivers design the EV charging network they want for their communities. They express ev charging demand in the places that matter to them most.
  
  They are educated on different charging types and speeds and when the are most useful.

  It's an app great especially for renters who desire to go electric.

  ## How I Built This

  The initial version of this app was designed with Figma Make. I drew several initial crude designs and wrote a prompt that led Figma to build the application.

  The original project is available at https://www.figma.com/design/ryCuQRutfDfvWAICBiY5rT/EV-Charging-Network-App.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
